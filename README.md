# Academic_Performance_Analysis_Project
🎯 Project Title

Academic Performance Distribution in Schools

📘 Domain

Data Science & Educational Analytics

🧠 Objective

The main goal of this project is to analyze the factors affecting students’ academic performance and visualize performance patterns across gender, parental education, lunch type, and test preparation courses.
This analysis helps identify key influences on learning outcomes and supports the UN SDG 4: Quality Education goal.


📈 Key Insights

🎓 Students with higher parental education levels scored better overall.

👩‍🎓 Female students slightly outperformed males on average.

🍱 Standard lunch students performed better than those with free/reduced lunch.

📚 Completing a test preparation course improved average scores.
